# Scrooge's Safe

一个可安装到手机主屏幕的家庭财务网页应用：电/气表读数与费用换算、储蓄账户、合同到期提醒、
表盘拍照识别和银行 CSV 账单导入。

**这是公开托管的空壳版，不含任何个人数据。** 应用数据使用 PBKDF2-SHA-256
派生密钥，并以 AES-256-GCM 加密保存在当前浏览器中。可选的家庭同步只会把
端到端加密密文保存到用户指定的私有 GitHub 仓库。

支持：

- 加密本地存储和密码加密备份
- 本地优先的夫妻双设备同步；断网可继续使用，联网后自动三方合并
- Face ID、Touch ID 或系统设备密码解锁
- 随应用发布、在设备本地运行的机械表 OCR；多区域放大识别并忽略红色小数轮，照片不会上传
- ING 及常见银行 CSV 的预览、去重和导入
- 旧版明文 JSON 备份迁移

首次打开需要设置主密码。主密码无法找回，请保存在密码管理器中。
家庭同步在“设置 → 家庭同步”中配置；两台设备使用相同的家庭同步密码，并各自保存
仅限同步仓库 `Contents` 读写权限的 GitHub Fine-grained Token。

在 iPhone 上使用：Safari 打开 → 分享 → 添加到主屏幕。安装后名称为
**Scrooge's Safe**，并使用仓库内的 App 图标。
